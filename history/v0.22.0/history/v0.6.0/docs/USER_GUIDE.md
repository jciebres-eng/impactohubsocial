# Guia rápido

**OSC:** crie o perfil → anexe documentos vigentes → cadastre uma oportunidade (itens × valor) → fracione se quiser → envie → acompanhe pendências → registre evidências nos marcos. Tem um código? "Meu plano → Tenho um código".
**Empresa:** defina objetivos e orçamento → crie programa/chamada e critérios → analise a shortlist e as lacunas → registre decisão e conflito → acompanhe marcos → exporte relatório.
**Prestador:** complete o perfil → verifique credenciais exigidas → responda a convites de projeto → registre entregas e assine → aguarde aceite. Seu plano não altera sua posição.
**Admin:** ver `ADMIN.md`.
Os rótulos de origem (autodeclarado, extraído, verificado, revisado) aparecem em todo dado.
